# Planning — รอบ 5 / FR-07–08

ใช้กลไกร่วมจากข้อมูลยืนยัน ฉบับหลักสูตร/นโยบาย/เปิดสอน ภาคอ้างอิง สาย และพารามิเตอร์ คืนแผนรายเทอมพร้อมสมมติฐานและเหตุผล มุมมองรายปีสรุปจากเทอมชุดเดียวกัน

ยังไม่เลือกสายให้สองทางเลือกโดยไม่เปลี่ยนสายจริง unknown ไม่เท่ากับ not_selected แสดงภาคคาดจบได้เมื่อเงื่อนไขที่จำเป็นพร้อม ไม่รับรองแผนสั้นที่สุด มี implementation และผลตรวจ local แล้ว ส่วนกฎ OPEN และการตรวจรับกับผู้ใช้จริงยังไม่ครบ
