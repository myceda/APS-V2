# Curriculum — รอบ 3 / FR-02–03

ข้อมูลหลักสูตร หมวด รายวิชา สาย เงื่อนไข กฎ และการเปิดสอนเป็นชุดมีฉบับและแหล่งอ้างอิง ผู้ดูแลนำเข้าร่าง ตรวจข้อผิดพลาดและเผยแพร่ตามสิทธิ์

แยก availability open/closed/unknown จาก confidence confirmed/planned ค่าเฉพาะภาคมีลำดับก่อนรูปแบบซ้ำ รวมเมื่อค่าเฉพาะภาคเป็น unknown ชุดข้อมูลทดลองยังไม่ใช่ฉบับรับรอง ยังไม่มี implementation
