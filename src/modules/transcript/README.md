# Transcript — รอบ 2 / FR-04–05

อ่าน PDF เป็นร่าง เก็บส่วนหัว รายวิชา ประวัติเรียนซ้ำ เกรดดิบ ยอดที่รายงาน และหน้าอ้างอิง แยกฟิลด์ present/not_present/unreadable กับสาย selected/not_selected/unknown
